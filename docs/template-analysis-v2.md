## 2. v1 → v2 的核心修正

| 问题 | v1 做法 | v2 做法 |
| --- | --- | --- |
| 主要算法被辅助技术抢分类 | 看到 `线段树` 就归 `数据结构`，看到 `异或` 就归 `基础算法` | 文件名 `——` 之前是 primary，之后是 secondary。primary 才决定一级目录 |
| 同算法家族散落多目录 | `线性基——异或所有结果.cpp` → `基础算法/位运算` | `线性基——异或所有结果.cpp` → `数学/线性代数/线性基/` |
| 同题两份无法区分 | 两条 `圆方树——模板.cpp` 都映射到同一目标路径 | 产生冲突时按内容生成可理解后缀，**两个文件均保留** |
| 置信度与可靠性脱节 | 命中一个关键词就标 `high` | 必须 primary 文件名匹配 + 分类家族与当前目录一致 才标 `high`；冲突或需复核一律降级 |

## 3. 推荐的内部目录结构

按 `primary_algorithm` → 算法家族 → 三级目录 组织。一级目录 9 个，不创建空的 `计算几何/`：


## 4. 分类规则（v2）

`docs/_analyze_templates.py` 的决策流程：

1. 拆分文件名：以 `——` / `--` / ` - ` 为分隔，取首段为 **primary**，余下为 **secondary techniques**
2. 在 `PRIMARY_MAP` 中查找 primary（去掉 `(2)` 等数字后缀）；命中即确定 (一级, 子路径)
3. 若 primary 未命中，使用当前目录 `DIR_FALLBACK_MAP` 兜底
4. 若仍未命中，对文件名再做一次全字段扫描（兜底）
5. 仍无命中 → `其他/未分类/`，confidence=`low`

confidence 判定：

| 规则 | confidence |
| --- | --- |
| 文件名 primary 命中，且 proposed_top 与 current_category 所在家族一致 | `high` |
| 文件名 primary 命中，但 proposed_top 跨家族（如 `图论` → `数学`） | `medium` |
| primary 未命中，靠目录兜底 / 关键词兜底 | `medium` |
| 冲突被自动消解（同名不同内容） | `medium`（且 `review_required=true`） |
| SHA-256 完全相同（重复文件） | `low`（且 `collision_status=duplicate_review`） |
| 完全无命中（`其他/未分类/`） | `low` |
