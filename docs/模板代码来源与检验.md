## 修复与取舍

- 修复了 Dijkstra 输出和数组容量、Prim / 树状数组求和溢出、ST 表层数与边界、多源 BFS 编译错误、Trie 删除计数与清空、模运算乘法溢出、FFT 负数系数舍入等问题。
- 无向图割点和 50 万节点树链剖分在长链压力测试中，原递归写法有爆栈风险；这两份改用静态数组与显式栈。FFT 采用静态数组的迭代蝶形，避免旧打印递归版的变长数组和大输入栈风险。其余适合递归的算法保留递归。
- Dinic、Hopcroft–Karp、多源 BFS 的队列改为定长数组。BSGS / exBSGS 保留映射表以查找离散对数状态。
- Johnson、动态 KD 树、可持久化 / 区间翻转 Treap 等算法已在扩充阶段加入，来源见[扩充模板来源](扩充模板来源.tsv)。

## 正确性检验与使用建议

`docs/verify_print_templates.py` 使用 C++17 编译整个模板目录，并对本页 32 份基础模板执行 1181 组随机差分和压力检验；包括 2 万节点长链割点、50 万节点长链 LCA。新增模板的检验另见总目录。

- `Dijkstra最短路.cpp` 对不可达点输出 `-1`，与 P4779 的输出约定不同。
- `线性筛质数.cpp` 一次输出三种筛法的计数，用于互相核对；例题链接不是可直接提交的输入输出格式。
- `Trie前缀树.cpp` 的 `main` 为空；使用时按具体题目的操作格式调用 `insert`、`erase`、`search`、`preword`。
