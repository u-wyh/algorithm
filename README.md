# 算法学习与练习

建议先在 `templates` 掌握经典题和常用写法，再到 `practices` 做更多题，练习识别什么时候该用这些算法。

| 目录 | 内容 |
| --- | --- |
| [templates](templates/README.md) | 学习算法时优先掌握的经典练习、示例和模板，按知识点查找。 |
| [practices](practices/README.md) | 日常刷题，按平台和题号归档，暂未按难度排序。 |
| [candidate](candidate/) | 待整理的提交代码。集中核对原题链接并补齐题意、数据范围和算法标签后，归入 `practices`。 |
| [docs](docs/) | 刷题指南和各类题单，可按算法标签找题，或从知识点查对应的练习。 |
| [tools/practice-index](tools/practice-index/README.md) | 更新专题题单、全量练习清单和算法标签题单时使用的脚本及数据。 |
| [可打印算法模板](可打印算法模板/README.md) | 适合打印复习的算法模板，整理中。 |
| [算法学习笔记](算法学习笔记/README.md) | 我的算法理解、学习方法和解题体会。 |
| [杂谈](杂谈/README.md) | 学习经历、感想和个人随笔。 |
