# 练习代码归档

## 按平台和题号找代码

- **洛谷**进入 [洛谷目录](洛谷/)。P、B、U、T 题号各自按 500 个编号分段。例如 P2153 在 [P2000-P2499](洛谷/P2000-P2499/) 下，P2500 在 [P2500-P2999](洛谷/P2500-P2999/) 下。
- **其他 OJ**各有一个目录：[Codeforces](Codeforces/)、[AtCoder](AtCoder/)、[SPOJ](SPOJ/)、[HDU](HDU/)、[UVa](UVa/)、[LibreOJ](LibreOJ/)、[LeetCode](LeetCode/)、[QOJ](QOJ/) 和 [UOJ](UOJ/)。洛谷收录的镜像题归到对应 OJ。
- **文件名**以已核实的题号或原题标识为准，例如 `CF507E.cpp`、`AT_PAST202309M.cpp` 和 `SPOJ_COT2.cpp`。同题的编号版本用 `_2`、`_3` 等后缀区分，使用「算法名——用途」格式的描述性名称照常保留。旧名称可查[文件改名对照](文件改名对照.md)。
- **待复核**的文件暂留本目录。历史记录见 [链接待复核清单](链接待复核清单.md) 与 [历史版本人工复核清单](人工复核清单.md)。

## 按算法练习

[按算法标签练习](../../docs/按算法标签练习.md)从源码文件头提取标签，链接到原题和对应实现。同一题可以在多个算法下出现，每个算法只列出实际用到它的版本。

原有入口仍可用：[全量算法练习清单](../../docs/全量算法练习清单.md) · [专题学习题单](../../docs/算法学习题单.md)

在仓库根目录更新标签题单：

```powershell
python docs/_preview_practice_archive.py --index "docs/按算法标签练习.md"
```
