# 数据结构

本目录按所维护的信息与操作组织代码。需要查找具体题目时，可从专题目录转到题单。

## 专题

| 目录 | 内容 |
| --- | --- |
| [并查集](并查集/README.md) | 集合合并、带权与可撤销版本 |
| [树状数组](树状数组/README.md) | 前缀信息维护与修改查询 |
| [线段树](线段树/README.md) | 区间修改、查询及可持久化实现；含目录内导航 |
| [线段树合并与分裂](线段树合并与分裂/README.md) | 动态维护多个集合 |
| [平衡树](平衡树/README.md) | 有序集合、排名与区间操作 |
| [左偏树](左偏树/README.md) | 可并堆、持久化实现与典型练习；已有专题 README |
| [树套树](树套树/README.md) | 多层数据结构组合查询 |
| [杂项数据结构](杂项数据结构/README.md) | 暂未归入上述专题的结构 |

## 建议学习顺序

先看并查集、树状数组和线段树，再根据操作需求读平衡树、左偏树、线段树合并与分裂或树套树。历史目录中另有 [LCT](../模板/LCT/README.md) 代码。

对应练习见[算法学习题单](../../docs/算法学习题单.md)；返回[知识地图](../README.md)。
