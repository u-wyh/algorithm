# 左偏树（可并堆）

## 简介

左偏树是一种支持快速合并的堆。普通二叉堆适合反复取最值，左偏树还适合不断把两个堆合成一个堆，例如集合合并、树上汇总和前 k 小方案的扩展。

## 核心思想与复杂度

保持堆序，并让右链尽量短：合并两棵堆时选较优的根，递归合并其右子树，再按空节点距离调整左右儿子。右链长度为 `O(log n)`，所以合并、插入单点和删除堆顶通常为 `O(log n)`；读取堆顶为 `O(1)`。带指定节点删除、懒标记或持久化的版本还需理解各自的附加维护。这里的复杂度指左偏堆基本操作，整道题还会有其他算法成本。

## 推荐学习顺序

1. 从 **P3377** 看堆序、空节点距离、`merge` 与删除堆顶；再用 **P1456** 练习大根堆和堆顶修改。
2. 看 **P1552**，理解为什么树形汇总会用到可并堆。
3. 看 **P4971** 的指定节点删除，以及 **P3261** 的懒标记，再读 **P3273** 的集合操作。
4. 看 **P4331** 中左偏树如何配合单调栈维护分段信息。
5. 先看随机对拍的可持久化模板，再看 **P2409** 的前 k 小方案，最后读 **P2483** 的最短路综合应用。

## 阅读提示

- 代码中的 `dist` 通常是到空节点的最短距离，不是节点深度；大根堆与小根堆的比较方向不同。
- 部分题目还用并查集定位当前堆根；它和左偏树上的父子关系不是一回事。
- 这些是学习过程中保存的独立程序。阅读时可先对照题意和文件头，再看原有注释与实现。
