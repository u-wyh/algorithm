# 图论

从图的表示与遍历开始，再按连通性、匹配、路径和流等问题进入相应专题。

## 专题

| 目录 | 内容 |
| --- | --- |
| [图论](图论/) | 图的基本算法、最短路及常见图模型 |
| [tarjan](tarjan/README.md) | 强连通分量、割点、桥和双连通分量；含目录内导航 |
| [二分图](二分图/) | 二分图判断、匹配与相关算法 |
| [欧拉回路](欧拉回路/) | 欧拉路径与回路 |
| [网络流](网络流/) | 最大流及流量约束模型 |
| [twosat](twosat/) | 2-SAT 建图与判定 |
| [kruskal重构树](kruskal重构树/) | 基于最小生成树的连通性与路径查询 |

## 建议学习顺序

先看[图论基础](图论/)，再按问题选择 Tarjan、二分图或欧拉路；熟悉图上建模后阅读网络流、2-SAT 和 Kruskal 重构树。各专题没有唯一的线性顺序。

对应练习见[算法学习题单](../../docs/算法学习题单.md)；返回[知识地图](../README.md)。
