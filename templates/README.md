# 算法模板

这个目录按知识域重新整理。一级目录负责大类，二级目录尽量保留具体算法名称，方便按关键词搜索。

## 目录说明

- `00_基础工具/`: 工具脚本、归档文档等非算法源码文件。
- `01_图论/`: 图论、二分图、网络流、欧拉路、Tarjan、2-SAT、Kruskal 重构树。
- `02_树上问题/`: 树上问题、LCA、倍增/ST 表、树链剖分、树上启发式合并、点分治、边分治、虚树。
- `03_字符串/`: KMP、扩展 KMP、AC 自动机、Manacher、Trie、后缀数组/后缀自动机、哈希。
- `04_数据结构/`: 线段树、树状数组、平衡树、并查集、左偏树、树套树等数据结构。
- `05_数学数论/`: 数学、数论、博弈论、01 分数规划。
- `06_动态规划/`: 动态规划相关模板。
- `07_搜索与贪心/`: 搜索、贪心、单调队列、单调栈。
- `08_离线分治/`: CDQ 分治、整体二分、分块、莫队、线段树分治。
- `09_基础技巧/`: 差分/前缀和、二分、排序、扫描线、双指针、位运算等基础技巧。
- `99_待整理/`: 暂时无法明确归类的模板。

## 备注

- 文件名仍沿用原来的中文描述，便于按关键词搜索。
- 原 `其他/` 中的文件已经按主题拆分到对应目录。
- 推荐使用 `rg --files templates` 快速查找模板文件。
