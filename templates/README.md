# 算法知识地图

本目录按现有知识分类组织学习代码。先选算法大类，再进专题查看模板、示例与题目实现；[算法学习题单](../docs/算法学习题单.md)把这些专题与可确认来源的练习题连接起来。

## 其他现有目录

- [`00_基础工具/`](00_基础工具/) 保存辅助工具和归档资料。
- [`模板/`](模板/) 是仍在使用的历史模板区，包含 LCT、2-SAT、基环树等实现；这里的题目也已纳入题单。

## 阅读约定

- 真正的算法模板用可读名称说明实现内容，例如 `可持久化左偏树模板-随机对拍.cpp`。
- 具体 OJ 练习使用题号及连续版本号，例如 `P3377.cpp`、`P3377_2.cpp`、`CF600E.cpp`、`AT_AGC002D.cpp`。
- 同一道题可以出现在多个知识点目录；题单按本仓库的学习归属收录，不限制题目的其他解法。
